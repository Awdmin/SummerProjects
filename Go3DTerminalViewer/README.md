## 3D terminal viewer written in GO

This project is a simulation of 3D objects with ASCII characters in the terminal (inspired by the famous 3D dounut)

Features I wish to implement:
- a variety of shapes (cubes, pyramids, circles)
- "shaders" on those objects so that the edges are nicely visible
- rotation of objects
- a format that is able to draw basicly any object from a description file


This project is made without using AI, and any library for easier work with terminal, only the stadard GO libraries
